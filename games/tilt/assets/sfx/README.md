# Sound effects (drop-in)

Put .ogg (preferred), .wav or .mp3 files here with these names; the game plays them automatically.

| Name | When |
| --- | --- |
| tap | Buttons on the start screen |
| slide | Tilt: marbles start sliding |
| plunk | Tilt: a marble drops into a hole |
| warp | Tilt: a marble uses a teleport pad |
| flip | Beam: a mirror flips or is placed |
| chime | Beam: a crystal lights up |
| buzz | Beam: a beam touches a shadow crystal |
| hint | A hint is shown |
| win | Level solved |
| star | Each star popping in on the level-complete screen |
